# fraud-detection-mlops





TP1 : Maîtrise de Git



Objectif: maîtriser Git pour la gestion de projets ML et l'appliquer dans un workflow MLOps (versionner le code, collaborer, traiter les conflits).



Ce qui a été fait:

\- Configuration de Git et création d'une clé SSH pour se connecter à GitHub.

\- Création du dépôt distant, clonage en local.

\- Ajout du fichier `eda.py` (premier commit), consultation de l'historique et des différences entre commits.

\- Création de la branche `experiment-eda`, publication sur GitHub.

\- Modification de la même ligne sur deux branches, puis fusion avec résolution du conflit.

\- Suivi des branches distantes (`git fetch --all`) et suppression d'une branche locale fusionnée.
